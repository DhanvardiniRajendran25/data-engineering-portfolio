Pipeline Architecture

How the data flows

Source → Blob → ADF Mapping Data Flows → three Medallion layers → Snowflake star schema. Every stage is named, typed, and separated so any layer can be re-run independently.

Stage Breakdown

What happens at each layer

Ingest

ADF pulls records from the Seattle Open Data REST API and lands them as raw CSV in Azure Blob Storage. No transformation at this stage — source fidelity is preserved exactly as received.

Bronze

ADF Copy Activity converts the raw CSV to Parquet. Schema is inferred from source; no column is dropped or renamed. Bronze is the audit baseline — queryable for debugging at any point.

Silver

ADF Mapping Data Flows run business-rule transformations: species codes are standardized, ZIP codes are normalized to 5-digit format, and NULL values are replaced with "Missing" sentinel dimension members to keep all foreign keys non-null.

Gold — Star Schema

MERGE statements load PET_LICENSE_FACT and four conformed dimensions: SPECIES_DIM, BREED_DIM, DATE_DIM, and ZIP_DIM. Surrogate keys are generated in Snowflake. MERGE makes every load idempotent — safe to re-run without producing duplicates.

Key Decisions

Why it was built this way

Decision 1

Surrogate keys over natural keys. Source license IDs are not stable — they can be reassigned or reused across data refreshes. Snowflake-generated surrogate keys decouple warehouse identity from source IDs and make SCD operations safe on every dimension table.

Decision 2

"Missing" sentinel dimension members instead of NULLs. A NULL foreign key in a fact table breaks GROUP BY queries and dimension joins silently. Inserting a "Missing" row in each dimension table and pointing unknown records there keeps all joins valid and makes missing data explicit in reports.

Decision 3

MERGE over INSERT for fact and dimension loads. A straight INSERT would produce duplicates on re-runs. MERGE matches on the natural key, inserts new rows, and updates changed attributes — making the pipeline safe to replay after a failure at any stage without manual cleanup.
