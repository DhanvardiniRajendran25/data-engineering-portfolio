Data Pipeline Architecture

From transcript to queryable knowledge

Agent System

9 specialist agents

01

Router

LangGraph intent classifier

Classifies user intent and routes to the correct specialist. 95.8% accuracy on held-out queries.

02

Semantic Search

Cortex vector search

Dense retrieval over SEMANTIC layer embeddings. Returns ranked chunks with episode + timestamp citations.

03

Fact Checker

Claim extraction + verification

Extracts factual claims from retrieved chunks and cross-checks them against other episodes in the corpus.

04

Timeline Analyst

Neo4j temporal traversal

Traces how topics, entities, and opinions evolved over time across episodes using the knowledge graph.

05

Cross-Episode Connector

Graph path traversal

Finds non-obvious connections between episodes and guests via shared entities in the Neo4j graph.

06

Entity Tracker

Named entity + graph lookup

Tracks people, companies, and concepts across the corpus — how many episodes, what context.

07

Topic Clusterer

Embedding clustering

Groups semantically related chunks across episodes to surface topic clusters the user didn’t explicitly ask for.

08

Contradiction Detector

NLI + graph comparison

Identifies when a guest contradicts a prior statement in a different episode — flags with timestamps.

09

Summarizer

LLM + citation assembly

Assembles agent outputs into a coherent cited answer with episode references and timestamp-linked URLs.

Key Decisions

Why it was built this way

Decision 1

120-second chunk size for the CURATED layer. Chunk size is the most consequential retrieval parameter: too long and retrieved chunks contain noise that confuses the LLM; too short and each chunk loses the conversational context needed to make a claim meaningful. 120 seconds captures a full thought in a podcast conversation while remaining small enough for precise retrieval.

Decision 2

Neo4j temporal graph alongside Snowflake Cortex Search. Vector search excels at finding semantically similar content but has no concept of time or entity relationships. The Neo4j graph adds structural reasoning: when did an entity first appear, how does it connect to other entities, did an opinion change over time? Neither system alone can answer those questions.

Decision 3

LangGraph specialist routing over a single generalist agent. A single LLM trying to handle semantic search, fact-checking, and timeline analysis in one prompt performs worse than a specialist on each task. The routing overhead is one classification call. Each specialist is independently evaluatable and improvable — critical when the system needs to be debugged or extended.
